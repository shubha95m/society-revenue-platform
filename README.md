# Society Revenue Platform

A multi-tenant SaaS platform designed to reduce or eliminate society maintenance charges through ethical revenue streams, cost optimization, and transparent governance.

## Vision
Zero maintenance charges for society members by creating a financial operating system for residential societies.

## Core Principles
- No ads
- No selling personal data
- Opt-in monetization only
- Radical transparency
- API-first architecture
- Mobile app readiness
- Multi-tenant by default
- Trust > Revenue

## User Types
1. **Platform Super Admin** - Controls global settings, society onboarding, fraud detection
2. **Society Admin** - Manages individual society operations, vendors, finances
3. **Society Members** - Residents with personal dashboards, service opt-in, voting rights
4. **Vendors** - Service providers connecting with societies

## Tech Stack (Planned)
- **Backend:** API-first (REST + WebSocket), JWT auth, RBAC
- **Database:** PostgreSQL + Redis
- **Frontend:** React/Next.js (SPA)
- **Mobile:** Flutter/React Native (Phase 2)
